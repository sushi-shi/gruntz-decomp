Destructors + ctors + operators + init fragments here still count. Under /Gy MSVC emits every function as a COMDAT and the linker pools the special-members (deleting ??_G/??_E dtors, ??0 ctors, ??4… operators) into shared low-address runs away from the TU block — so they inflate the scatter. The core view removes exactly that set. Fragmentation is a property of the retail link layout, not the reconstruction: MSVC/link concatenates each TU's COMDATs in source order, so a TU is mostly one contiguous block. Data grouping is our src/ files (kept close to the original TUs). Source: scatter*.json.
